# Replication Package: Failure Attribution and Recovery in Long-Horizon LLM Agents

This repository contains supplementary material for the anonymized manuscript:

**"Toward Closing the Loop on Failure Attribution in Long-Horizon LLM Agents:
A Systematic Review, Taxonomy, and Research Agenda"**

The materials support the systematic-review protocol, study selection,
coding, and synthesis reported in the manuscript.

## Contents

### `data/llm_agent_recovery_review_data.xlsx`

The workbook contains four worksheets:

1. **Literature Catalogue**
   - Structured catalogue of the 68 studies included in the review.
   - Records study metadata, methodology, benchmarks, evaluation,
     limitations, research-question coverage, integration gaps,
     and recovery-stage contributions.

2. **PRISMA Flow Counts**
   - Record counts used to construct the PRISMA-informed study-selection flow.

3. **Search Log**
   - Database-specific search strings and filters used during literature retrieval.

4. **Eligibility Criteria**
   - Inclusion and exclusion criteria applied during screening and eligibility assessment.

## Review Scope

The review examines literature relevant to failure detection,
localization/attribution, rollback and recovery, context and memory handling,
and reliability evaluation in long-horizon LLM-agent and multi-agent systems.

## Reproducibility

The supplementary data are provided to make the study-selection,
coding, and synthesis process auditable and reproducible.

## Anonymization

Author identities and identifying institutional information have been
removed for peer review.
